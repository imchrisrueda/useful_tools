# Skills

Directorio para skills reutilizables de desarrollo con IA. Todavía no contiene skills.

Cada skill se guarda en `skills/<nombre>/` con un `SKILL.md` que describe su propósito,
cuándo usarla, requisitos, pasos y cómo comprobar el resultado.
Los scripts, referencias y assets que necesite se guardan dentro de esa misma carpeta.

Las instrucciones específicas de Herdr están en
[herdr_usage/AGENTS.md](../herdr_usage/AGENTS.md).
