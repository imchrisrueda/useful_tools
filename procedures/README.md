# Procedimientos

Directorio para procedimientos de desarrollo con IA. Todavía no contiene procedimientos compartidos.

Usa un archivo Markdown por procedimiento; crea una carpeta propia cuando necesite
scripts, ejemplos o assets. Describe objetivo, requisitos, pasos, comprobación del
resultado y recuperación o reversión cuando corresponda.

Los procedimientos propios de una herramienta se mantienen junto a ella.
Por ejemplo, la configuración de Herdr está en
[herdr_usage/docs/agent-setup.md](../herdr_usage/docs/agent-setup.md).
